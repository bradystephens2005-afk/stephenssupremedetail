Owner notes

Private checklist and tools for running the shop. This page isn't linked anywhere and asks search engines not to list it. Don't put passwords or bank details here.

Stripe Payment Links

    Links are set at the top of assets/site.js. After editing, run python3 build.py and redeploy.

    Each link should have: customer name required, US shipping address, adjustable quantity, Stripe Tax on, and the right price and shipping rate.

    Optional: in each link's "After payment" setting, redirect to:

    • Cordless Window Perch: https://perch-and-purr.netlify.app/thank-you/?product=window-perch
    • The Cozy Window Bundle: https://perch-and-purr.netlify.app/thank-you/?product=cozy-window-bundle
    • Reusable Fur Lifter: https://perch-and-purr.netlify.app/thank-you/?product=fur-lifter

    USPS box calculator

    Measure the folded perch in its shipping box. Over 1 cubic foot, USPS bills by size (volume ÷ 139). Any side over 22 in adds a $4.50 fee.

    Before launch

    1. Fix the perch Payment Link in Stripe so it charges $32.00 with free shipping, then paste it into site.js.
    2. Swap the drawings in /images for your own photos. Don't use Amazon or manufacturer photos without written permission.
    3. Measure the folded perch box and run the calculator above to make sure free shipping still pays.
    4. Add the perch size to PERCH_SIZE in build.py.
    5. In Netlify, turn on form detection (Forms), then redeploy.
    6. Get the SC Retail License ($50) through MyDORWAY.
    7. Place one real order yourself, then refund it in Stripe.
    8. Read the About page and policies and change anything that isn't right.

    Fulfillment options

    • Amazon shipped to the customer: a gray area in Amazon's terms, and it arrives in an Amazon box.
    • CJ Dropshipping, US warehouse: hands-off, but check stock, ship times and packaging before promising 3 days.
    • Ship from home: buy stock, print labels with Pirate Ship. Most control, most work.

    SC sales tax

    • Retail License: $50 through MyDORWAY, before your first sale.
    • File Form ST-3 every month, even with zero sales.
    • Stripe Tax collects the tax but doesn't file it. Pull Stripe's tax report each month and use it to file.
